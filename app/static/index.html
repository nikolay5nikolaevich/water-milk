Другие способы загрузки и источники данных

Учебные сценарии D01–D05, загруженные вашим скриптом, читаются из примечаний сделок. Также распознаются примечания с явными строками «Клиент:» и «Менеджер:».

История обычных чатов — отдельный источник. Если в сделке есть беседа, но доступ к сообщениям канала не настроен, приложение покажет это явно. Служебные заметки не считаются перепиской.

Новая переписка

Подойдёт текст из CRM, почты или любого чата. Перед загрузкой обезличьте данные.

Одна строка — одно сообщение. Роли: «Клиент:» и «Менеджер С01:». Имена можно заменить кодами сотрудников. Время при необходимости включите в текст сообщения.

Правила для оценки

Для рабочих диалогов нужна утверждённая база компании. Учебные цены и сроки не используются как реальные условия.
Загрузить или изменить базу

Укажите версию, scope: company и источник, владельца, статус и период действия каждого правила. В пакет попадут только approved на дату диалога. Сохранённые разборы сохраняют свою копию правил.

Оценка через вашу подписку

  1. Добавьте правила. Для реальных переписок замените учебную базу на утверждённые условия компании.
  2. Откройте чат сделки. Подключите аккаунт, нажмите «Открыть чат» у сделки и просмотрите загруженные сообщения. Для других источников есть ручной ввод.
  3. Нажмите «Проверить ответ менеджера». Приложение само передаст диалог и правила Codex через вход по вашей подписке ChatGPT. API-ключ не нужен.
  4. Получите результат. Оценки, замечания, цитаты и ссылки на правила появятся после проверки автоматически. Вручную переносить JSON не требуется.
  5. Подтвердите разбор. Человек проверяет смысл замечаний и принимает или оспаривает результат. Только подтверждённые фактические результаты входят в средний балл.

Как модель ссылается на правила

В каждом задании находится применимая версия базы с ID записей. Для замечания модель обязана вернуть сообщение, точную цитату и ID правила. По ссылке в разборе открывается сохранённый текст правила. Проверка ссылок подтверждает происхождение доказательств; смысл вывода проверяет человек.

Если информации недостаточно

Критерий получает Н/Д, общий балл не рассчитывается. При неполной истории оцениваются только видимые сообщения. Действия в CRM не входят в оценку текста. Предложения в базу остаются черновиками.

Что хранится

Переписки, результаты, копии правил и журнал решений сохраняются в SQLite на этом компьютере. Приложение читает данные подключённого аккаунта amoCRM. По нажатию кнопки выбранная переписка и применимые правила передаются Codex по вашей подписке.
