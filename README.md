# water-milk

Учебный MVP контроля качества общения с клиентами в amoCRM.

Комплект содержит план настройки CRM, базу знаний, критерии оценки, промпт для ИИ, пять тестовых диалогов с эталонными разборами и сценарий демонстрации.

Начать с [инструкции исполнителю](mvp/00_НАЧАТЬ_ЗДЕСЬ.md). Общий объём работ описан в [плане MVP](akvamilk_mvp_plan.md).

## Получить материалы

```bash
git clone https://github.com/nikolay5nikolaevich/water-milk.git
cd water-milk
```

Откройте Markdown-файлы в редакторе или прямо на GitHub. Установка зависимостей не требуется.

## Статус

Материалы подготовлены для учебной демонстрации. Коммерческие условия и диалоги вымышлены. Подключение Telegram, настройка amoCRM и фактический прогон ИИ подтверждаются отдельно в журнале проверок.
